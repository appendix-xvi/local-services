# AGENTS Instructions

- Keep this repository minimal and practical.
- Do not expand scope unless explicitly requested.
- Do not add unrelated tooling.
- Do not turn this into a DevOps platform, lab, or framework.
- Prefer Docker Compose recipes over custom Dockerfiles.
- Every new service must follow the same directory structure.
- Every service must include `compose.yml`, `.env.example`, and `README.md`.
- Never commit real credentials, tokens, kubeconfig, cloud profiles, or company/internal endpoints.
- Documentation must stay concise and practical.
