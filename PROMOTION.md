## Reddit / community post

I created a small practical repository for local development services using Docker Compose.

It is not meant to be a DevOps platform or a big lab environment. It is just a clean collection of service folders with `compose.yml`, `.env.example`, and a short README for each service.

Current services:

- Redis
- MySQL
- PostgreSQL
- Azurite
- LocalStack

The goal is to reduce repeated setup work when testing local applications that need common dependencies.

Repository:
https://github.com/appendix-xvi/local-services
